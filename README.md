# Application To-Do List PHP

Cette application web est une **to-do list** développée en PHP, HTML, CSS, JavaScript, et SQL. Elle permet aux utilisateurs de créer, modifier, supprimer et afficher des tâches dans une interface conviviale.

## Fonctionnalités

- **Connexion utilisateur** : Authentification via un système de login et logout.
- **Gestion des tâches** : Ajout, modification, suppression et affichage des tâches.
- **Base de données MySQL** : Stockage des informations relatives aux tâches et utilisateurs.
